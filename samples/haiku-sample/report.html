# Vezafra: reference manual
# Vezafra reference manual

Vezafra is a small imperative language. A program is a list of statements. The grader calls the function `budru solve(...)` with arguments and prints the value it returns.

## Words and values
- Function definition: `budru`. Conditionals: `glugi` / `supine`. Loops: `botu`. Return: `kezvai`.
- Booleans: `vedreebe` and `kreedena`. Integers: `0`, `42` (negative numbers use the prefix negation operator `-`). Strings: double quotes, e.g. "hi".
- Lists are written `[a, b, c]`. Values are immutable: `append` returns a new list.
- A function that does not return a value yields `none`.
- Printed values: integers as digits, booleans as `true`/`false`, strings as-is, lists as `[a, b]`. Strings inside a list are in double quotes, e.g. `["a", 1]`.

## Statements
- Assignment: `name = expression`. The first assignment inside a function creates the variable.
- Blocks start with `poutrai` and end with `teevu`. Statements inside a block follow the same rules.
- Statement endings: each simple statement ends with `.`.
- Identifiers are plain letters, digits and underscores (not starting with a digit).

## Operators and precedence
- Negation: `-x`. Logical not: `!x`. Both bind tighter than any binary operator.
- Binary operators, lowest binding first (same line = same precedence, grouped left to right):
1. `||`
2. `+`, `-`
3. `&&`
4. `==`, `!=`, `<`, `<=`, `>`, `>=`
5. `*`, `/`, `%`
- Calls and indexing bind tightest of all.
- Parentheses group as usual.

## Calls
- A call is written `name(arg, ...)`. Built-in and user-defined functions use the same form.

## Indexing
- `xs[i]` reads an element. Indices start at **0**: the first element is `xs[0]`, the last is `xs[0 + len(xs) - 1]`.
- Indexing outside the valid range is a runtime error.

## Truthiness
- `kreedena`, `vedreebe`: as written. `none`: false.
- The integer 0 is false. An empty list or empty string is false. Any other integer is true.

## Integer arithmetic
- `/` on integers rounds toward zero: `-7 / 2` evaluates to -3.
- `%` takes the sign of the divisor: `-7 % 3` evaluates to 2, and `7 % -3` evaluates to -2.
- Division or modulo by zero is a runtime error. `+` also joins two strings.

## and / or
- `and` and `or` short-circuit. They return a boolean: `0 or 5` evaluates to true, `vedreebe and 0` evaluates to false.

## Built-in functions
- `brupu(x)`: number of items in a list or characters in a string.
- `trimai(xs, v)`: a new list with `v` added at the end.
- `briree(x)`: the printed form of `x` as a string.
- `kepen(x)`: prints `x` on its own line.

## Limits
- Programs get a bounded number of steps, a bounded call depth and bounded list and string sizes. Exceeding a limit (for example an infinite loop) is an error.

## Worked examples (executed when this manual was generated)

kepen(7 % - 3) .

```

### Truthiness in conditions

  kepen("zero is true") .
teevu supine poutrai
  kepen("zero is false") .
teevu
glugi[] poutrai
  kepen("empty list is true") .
teevu supine poutrai
  kepen("empty list is false") .
teevu
```
Output:
```

```

### Indexing
```

kepen(xs[0]) .
kepen(xs[2]) .

- `trimai(xs, v)`: a new list with `v` added at the end.
- `briree(x)`: the printed form of `x` as a string.
- `kepen(x)`: prints `x` on its own line.

## Limits
- Programs get a bounded number of steps, a bounded call depth and bounded list and string sizes. Exceeding a limit (for example an infinite loop) is an error.
